# Objetos robados

Al iniciar cada caso, el juego elige al azar un objeto de esta lista:

- La Mona Lisa
- El grito
- El concierto
- La tormenta en el mar de Galilea
- El Huevo de Fabergé «Tercer Huevo Imperial»
- La Salera de Francisco I
- El Diamante Hope
- El Códice Calixtino
- El busto de Nefertiti

La lista está implementada como `STOLEN_OBJECTS` en `script.js`. Mantén sincronizados este documento y el arreglo cuando se añadan o cambien objetos.

## Autoría mostrada en el expediente

Cuando se conoce, el terminal muestra el autor junto al objeto. Las atribuciones discutidas aparecen expresamente como tales.

| Objeto | Autor mostrado |
|---|---|
| La Mona Lisa | Leonardo da Vinci |
| El grito | Edvard Munch |
| El concierto | Johannes Vermeer |
| La tormenta en el mar de Galilea | Rembrandt van Rijn |
| El Huevo de Fabergé «Tercer Huevo Imperial» | August Holmström, maestro orfebre de Fabergé ([V&A](https://www.vam.ac.uk/exhibitions/faberge)) |
| La Salera de Francisco I | Benvenuto Cellini |
| El Diamante Hope | No se muestra autor; no se conoce uno |
| El Códice Calixtino | Aymeric Picaud, atribución discutida; el códice fue compilado posiblemente por Picaud ([Yale](https://alumniacademy.yale.edu/sites/default/files/2020-07/Codex%20Calixtinus.pdf)) |
| El busto de Nefertiti | Tutmose, atribución probable según los Museos Estatales de Berlín ([SMB](https://www.smb.museum/fileadmin/website/Presse/Pressematerial/2009/10/6_Highlights_engl..pdf)) |
